## 一、先花 5 分钟，建立整体印象

AI 这个词太大了。本知识库讲的是**当前最主流的那一类 AI：大语言模型（LLM）**，也就是 ChatGPT、Claude、通义千问背后那套技术。

用一句话概括它在干什么：

> **它读了你输入的每个字，然后一个词一个词地猜下一个词最可能是什么。**

听起来简单得离谱，但「猜得足够准」就能写代码、写文章、做翻译、回答问题了。

### 它是怎么被"教"出来的

```
① 读海量文本（互联网、书籍、代码）      → 学会语言的规律
② 学习模仿人类回答（专家写的答案）        → 学会"好好说话"
③ 根据人类偏好调整（哪个回答更好）        → 学会"说人话、说对话"
```

三阶段分别叫：**预训练 → 监督微调 → 人类反馈强化学习**。第 2 篇会细讲。

### 它为什么有时候胡说八道

因为它**本质是在猜下一个最可能的词，而不是在查资料**。所以它会把"听起来很合理"的内容说出来，哪怕那是编的。这叫**幻觉**。

理解这一点，你就理解了 AI 大部分「聪明」和「蠢」的表现。

## 四、小白最容易误解的 8 件事

先看一眼，能省你很多弯路：

| 误解 | 事实 |
| --- | --- |
| **AI 会去网上查资料再回答** | 不会。它只根据"训练时记住的"和"你这次给的"来回答。除非你特意给它接了搜索或知识库 |
| **AI 记得我们上次聊了什么** | 在同一个对话里记得，新开对话就忘了。它没有"长期记忆"，除非产品特意做了 |
| **它说得很流畅，所以一定对** | 流畅和正确是两件独立的事。它编造的内容也很流畅 |
| **训练一次就永久会了** | 它不会从和你的对话中学习。每次对话结束，它对世界的认知没变 |
| **模型越大越聪明，所以要选最大的** | 大模型更贵更慢。很多任务小模型够用，甚至更好 |
| **temperature 设成 0 就一定不瞎说** | 更稳定、更重复，但幻觉依然存在 |
| **我给它资料它就能学会** | 那叫"放进上下文"，不是"学会"。对话结束就忘了 |
| **AI 能完全替代人做决策** | 它擅长生成和建议，不擅长承担责任 |

## 五、怎么判断自己学会了

每篇末尾都有「用一句话解释给朋友听」的小练习。如果你能不用术语把它讲明白，说明真懂了。

比如学完第 02 篇，你应该能回答：

> 「为什么 ChatGPT 有时会把没有的事说得特别肯定？」

如果你的回答是「因为它只是在猜下一个词，不是真的在查证」，那就到位了。
