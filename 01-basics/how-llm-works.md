# 02 · 大模型是怎么工作的

> 这一篇是整个知识库的核心。读完你就能用自己的话解释：
> 为什么 ChatGPT 能对话？为什么它会编？为什么它时不时就"忘事"？

---

## 一、核心机制：一个词一个词地猜

### 1.1 最小例子

你输入：**「今天天气真」**

模型要回答：下一个词最可能是什么？

它可能给出概率：

| 候选词 | 概率 |
| --- | --- |
| 好 | 45% |
| 不错 | 25% |
| 热 | 12% |
| 差 | 8% |
| 其他 | 10% |

它挑一个（比如"好"），然后把「今天天气真好」再喂回去，继续猜下一个……

```
你输入：  今天天气真
第1步 →   今天天气真好
第2步 →   今天天气真好，
第3步 →   今天天气真好，适合
...
直到输出「结束符」或达到长度上限
```

**这个循环叫「自回归生成」。**

### 1.2 关键认知

| 你以为 | 实际 |
| --- | --- |
| AI 先想好整段话再输出 | 它一次只算一个词，边算边出 |
| AI 在回答你的问题 | AI 在「续写」你的文本 |
| 回答是"查"出来的 | 回答是"生成"出来的 |

**最后一条最重要**：它没有数据库。每次输出都是根据概率现场生成的。

### 1.3 为什么你会觉得它在"回答"

因为训练数据里，「用户问 X → 助手答 Y」这种格式出现了亿万次。模型学会了：**看到问题，就该续写一个答案。**

## 二、为什么它能猜得这么准：Transformer

### 2.1 猜下一个词需要什么信息

看这句话：

> 「小明把苹果递给小红，因为**她**饿了。」

「她」指谁？需要看上下文。
再看：

> 「我把这本书放在了桌子上，然后**它**被风吹走了。」

「它」指书，不是桌子。

**要猜得准，必须理解"哪些词和哪些词有关"。**

### 2.2 传统方法的困境

早期模型（RNN）是**从左往右一个字一个字读**，读到后面时前面的信息已经被"冲淡"了。

打个比方：读完一本 500 页的书，问你第 3 页第三段的细节——早忘了。

### 2.3 Transformer 的解法：注意力机制

**核心思想**：处理每个词时，**同时看所有词，并决定该重点看哪些**。

```
句子：小明 把 苹果 递给 小红 ， 因为 她 饿了
                                ↑
                          处理「她」这个词时

模型自动计算：「她」应该重点关注谁？
  小明  → 权重 0.05
  苹果  → 权重 0.02
  小红  → 权重 0.85  ← 找到了！
  饿了  → 权重 0.05
```

**这就是"注意力"。**

好处：
- **不受距离限制**：第 1 个词和第 10000 个词可以直接关联（早期模型做不到）。
- **可以并行计算**：所有词同时处理，不像 RNN 必须一个个来 → 能用 GPU 大规模加速 → 这是大模型能"大"起来的前提。

### 2.4 Transformer 内部长什么样（简化）

```
输入文字
   ↓
[分词] 把文字切成 token
   ↓
[向量化] 每个 token 变成一个数字列表（向量）—— 让计算机能算
   ↓
┌──────────────────────────────┐
│ 重复 N 层（N 可能几十到上百）  │
│  ┌────────────────────────┐  │
│  │ 注意力层                │  │ ← 看上下文，找到该关注的词
│  ├────────────────────────┤  │
│  │ 前馈网络层              │  │ ← 对信息做加工和转换
│  └────────────────────────┘  │
└──────────────────────────────┘
   ↓
[输出层] 算出"下一个词"的概率分布
```

**参数主要在哪里？**
大部分在「前馈网络层」里。所谓"7B 模型"（70 亿参数），就是这些数字的总量。

## 三、token 是什么（很关键）

### 3.1 定义

**token 是模型处理文本的最小单位**，介于「字」和「词」之间。

```
"Hello world"        → ["Hello", " world"]        2 个 token
"人工智能"            → ["人工", "智能"]           2 个 token
"ChatGPT"            → ["Chat", "GPT"]            2 个 token
"我爱你"              → ["我", "爱", "你"]         3 个 token
```

**粗略估算**：
- 英文：1 个 token ≈ 0.75 个单词
- 中文：1 个汉字 ≈ 1–2 个 token

### 3.2 为什么关心 token

因为**一切都是按 token 算的**：

| 项目 | 单位 |
| --- | --- |
| 你付多少钱 | 每千/百万 token |
| 能记住多少上下文 | token 数量（如 128K token） |
| 输出速度 | token/秒 |

### 3.3 上下文窗口

模型一次能"看到"的 token 总数，叫**上下文窗口**。

```
[系统提示] + [历史对话] + [你的新问题] + [它要生成的回答]
└──────────────── 全部加起来 ≤ 上下文窗口 ────────────────┘
```

**注意**：
- 超出窗口 → 最早的内容会被"挤出去"（或直接报错）
- 这就是为什么聊久了，AI 会忘记开头说的

## 四、它为什么记不住上一轮对话

关键点：**模型本身没有记忆。**

有记忆，是因为**应用每次都把历史对话重新发一遍**：

```
第 1 轮：你 → [问题1]                       模型 → [答案1]
第 2 轮：你 → [问题1][答案1][问题2]         模型 → [答案2]
第 3 轮：你 → [问题1][答案1][问题2][答案2][问题3]  ...
```

每次都是一次全新的、无状态的请求，只是"上下文"里塞了之前的话。

**推论**：
- 新开一个对话 → 上下文清空 → 它完全不记得你
- 聊得越久 → 每次发送的内容越多 → 越贵、越慢
- 长对话到上限 → 早期内容被截断 → 它"失忆"

## 五、为什么它会一本正经地胡说（幻觉）

理解了"猜下一个词"，就理解了幻觉。

### 5.1 三种成因

**① 它优化的是"像不像真的"，不是"是不是真的"**

训练目标是"猜中下一个词"，而训练数据里绝大多数句子都是通顺合理的。
所以模型倾向于生成**读起来合理**的内容——包括合理但不存在的。

> 例子："请介绍一下张三丰的第三十七代传人李某某的著作"
> 模型不知道这个人，但"介绍一个人 + 列举著作"这个模式太熟悉了，于是它编了一个。

**② 没有"我不知道"这个选项被充分训练**

如果模型回答"我不知道"，在训练数据里这种回答相对少。而"编一个答案"更符合学到的模式。

**③ 知识有截止日期 + 没有查证能力**

它只知道训练时见过的。训练之后发生的事、内部文档、你公司的数据，它都不知道。
**但它不会说"我不知道"，它会根据"通常情况"推测并自信地说出来。**

### 5.2 怎么减少

| 方法 | 原理 | 效果 |
| --- | --- | --- |
| 让它查资料（RAG） | 把真实文档塞进上下文 | 显著，见第 06 篇 |
| 要求"不知道就说不知道" | 用提示词改变行为倾向 | 中等 |
| 要求引用来源 | 迫使它基于给定内容 | 中等 |
| 降低 temperature | 减少随机性 | 轻微 |
| 人工核对关键信息 | 唯一可靠的兜底 | 最强 |

## 六、完整流程复盘

一次对话，内部发生了什么：

```
① 你的文字 → 切成 token
② token → 向量（数字）
③ 加上位置信息（让模型知道顺序）
④ 经过 N 层 Transformer（注意力 + 前馈）
⑤ 输出层算出下一个 token 的概率
⑥ 按概率选一个（受 temperature 影响）
⑦ 把新 token 拼上，回到 ④
⑧ 直到生成"结束"或达到长度限制
⑨ token → 文字，返回给你
```

**"思考"发生在第 ④ 步，"记忆"只在上下文里，"知识"在参数里。**

## 七、常见困惑

**Q：它是在搜索吗？**
不是。除非你另外给它接了搜索工具。它只根据参数和上下文生成。

**Q：为什么同一个问题问两次，答案不一样？**
因为第 ⑥ 步是「按概率选」，有随机性。`temperature` 控制这个随机程度。

**Q：它知道自己是 AI 吗？**
它知道"训练数据里有大量关于 AI 自我描述的内容"，所以能说出"我是一个 AI 助手"。但这是学来的表述，不代表有自我意识。

**Q：为什么它有时算术会错？**
因为它在"猜下一个 token"，而不是在执行计算。数学需要精确步骤，而概率生成天然不精确。让它"一步步写出来"（思维链）能改善，因为它把中间结果写进了上下文。

**Q：为什么它对提示词敏感？**
因为不同措辞会激活不同的"续写模式"。训练数据里"详细解释"和"简短回答"对应不同的文本模式。

---

## 八、用一句话解释给朋友听

> 「大模型就是一个超大号的"猜下一个词"机器。为了猜得准，它学会了语言的规律和海量知识。它一次只算一个词，边算边出，所以它是在"续写"而不是"查证"——这就是它既聪明又会编的原因。它没有记忆，是应用每次把对话历史重新发给它。」
