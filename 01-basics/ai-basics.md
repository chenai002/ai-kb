# 01 · AI 到底是什么：一张图理清所有概念

> 读完这篇，你不会再把「AI / 机器学习 / 深度学习 / 大模型 / 生成式 AI」混着用。
> 不用任何数学基础。

---

## 一、先用一句话说清

这些词不是并列关系，而是**一层套一层**的：

```
┌─────────────────────────────────────────────────┐
│ 人工智能 AI                                      │
│  「让机器做需要智能的事」                         │
│                                                 │
│  ┌───────────────────────────────────────────┐  │
│  │ 机器学习 Machine Learning                  │  │
│  │ 「不给规则，给例子，让机器自己找规律」      │  │
│  │                                           │  │
│  │  ┌─────────────────────────────────────┐  │  │
│  │  │ 深度学习 Deep Learning              │  │  │
│  │  │ 「用多层神经网络来找规律」            │  │  │
│  │  │                                     │  │  │
│  │  │  ┌───────────────────────────────┐  │  │  │
│  │  │  │ 大语言模型 LLM                │  │  │  │
│  │  │  │ 「用海量文本训练的超大网络」    │  │  │  │
│  │  │  └───────────────────────────────┘  │  │  │
│  │  └─────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

**所以**：所有大模型都是深度学习；所有深度学习都是机器学习；但不是所有 AI 都是机器学习（比如早期的下棋程序是人工写的规则）。

## 二、逐层解释（用生活例子）

### 2.1 人工智能 AI：最大的筐

**定义**：让机器表现出「像人一样聪明」的行为。

**早期做法（规则式）**：
> 想做一个垃圾邮件过滤器 → 人工写规则：「包含"中奖"就标垃圾」。

问题：骗子换个词就骗过去了。规则永远写不完。

### 2.2 机器学习：从「写规则」变成「给例子」

**新思路**：不给规则，给 10 万封邮件，标注哪些是垃圾、哪些不是，让机器自己总结规律。

| | 传统编程 | 机器学习 |
| --- | --- | --- |
| 你给机器什么 | 规则 + 数据 | 数据 + 答案 |
| 机器给你什么 | 结果 | 规则（模型） |
| 谁在"想办法" | 你 | 机器 |

**关键概念：模型（Model）**
机器从例子里总结出来的「规律」，存成一个文件，就是模型。
可以理解成：**一个超大号的「如果…就…」规则集，规则多到你写不出来，但机器能自动生成。**

### 2.3 深度学习：用「神经网络」来总结规律

**问题**：复杂问题（比如认猫）的规律太复杂，普通方法总结不出来。

**解法**：模仿大脑，设计一种叫**神经网络**的结构，一层一层地提取特征。

认猫的例子：
```
图片 → [第一层：找边缘] → [第二层：找耳朵、胡须] → [第三层：组合成猫脸] → "是猫"
```

- 层数少 → 浅层学习（只能做简单任务）
- **层数多（"深"）→ 深度学习**（能做复杂任务）

**"训练"到底在干什么？**
网络里有很多「旋钮」（参数）。训练就是：**不断调整旋钮，让输出越来越接近正确答案。**
调旋钮的数学方法叫「反向传播」，你不需要知道细节，只需要知道：**训练 = 大量试错 + 调旋钮。**

### 2.4 大语言模型 LLM：专门处理语言的超大网络

**做法**：同一个网络结构，但：
- **喂的数据是文字**（书籍、网页、代码），不是图片；
- **任务统一成「猜下一个词」**；
- **网络特别大**（参数从几十亿到上万亿）。

**为什么"猜下一个词"这么厉害？**
因为要准确猜下一个词，模型必须"懂":
- 语法（"我吃饭"不是"我饭吃"）
- 常识（"太阳从__升起"→ 东边）
- 逻辑（数学题、代码的下一步）
- 甚至世界的知识

**所以**：为了猜得准，它被迫学会了很多东西。这是大模型能力的来源，也是它幻觉的来源（它学的是"怎么说像真的"，不是"什么是真的"）。

## 三、生成式 AI 是什么

「生成式」是相对于「判别式」说的：

| | 判别式 AI | 生成式 AI |
| --- | --- | --- |
| 干什么 | 做选择题 | 做简答题 |
| 例子 | 这是猫还是狗？这封邮件是不是垃圾？ | 写一段广告文案、画一张图、写一段代码 |
| 输出 | 一个标签 / 一个分数 | 一段全新的内容 |

ChatGPT、Claude、Midjourney、Sora 都是生成式 AI。

**注意**：它们不是"从网上复制"，而是根据学到的规律**现场生成**新内容。所以每次回答可能都不一样。

## 四、多模态是什么

**模态**：信息的类型，比如文字、图片、声音、视频。

**多模态模型**：能同时处理多种类型。
- 能看图 → 你发张照片问「这是什么」
- 能听声音 → 语音助手
- 能生成图 → 你描述，它画

现在主流的大模型大多是多模态的。

## 五、AI 家族全景（简单版）

```
AI
├── 规则式（早期）
│   └── 专家系统、早期下棋程序
│
├── 机器学习
│   ├── 传统方法（决策树、SVM…）
│   │   └── 用于：风控、推荐、预测
│   │
│   └── 深度学习
│       ├── 计算机视觉（看图）
│       │   └── 人脸识别、自动驾驶
│       ├── 语音（听/说）
│       │   └── 语音转文字、语音助手
│       └── 自然语言处理（NLP）
│           └── 大语言模型 LLM ★ 本知识库的重点
│               ├── 文本
│               ├── 代码
│               └── 多模态（文+图+音）
```

## 六、小白最容易搞混的几组词

| 混淆 | 澄清 |
| --- | --- |
| **AI 和机器学习** | AI 是目标，机器学习是实现方式之一 |
| **深度学习和神经网络** | 神经网络是结构，「深层」的神经网络叫深度学习 |
| **大模型和 ChatGPT** | 大模型是技术/文件；ChatGPT 是产品（用大模型做的应用） |
| **模型和算法** | 算法是"训练方法"，模型是"训练出来的结果" |
| **参数和超参数** | 参数是机器自己调的旋钮；超参数是你手动设的（如学习速度、层数） |
| **训练和推理** | 训练 = 教它；推理 = 用它。我们日常用 AI 都是在推理 |
| **开源模型和闭源模型** | 开源能下载到自己机器跑；闭源只能调 API |

## 七、你可能关心的几个问题

**Q：AI 真的"理解"语言吗？**
争议很大。它确实学到了大量规律，但"理解"的定义本身有哲学争议。实用角度：**它能很好地完成任务，但不该假定它有人的理解。**

**Q：AI 有意识吗？**
目前没有证据。它说的话像有意识，是因为训练数据里有大量人类表达。

**Q：为什么突然就爆发了？**
不是突然。三件事凑齐了：
1. **算法**：2017 年 Transformer 结构出现（见第 02 篇）；
2. **算力**：GPU 大规模可用；
3. **数据**：互联网文本足够多。

**Q：学 AI 一定要会数学吗？**
做研究要；**用 AI、理解原理、做产品，直觉够了**。
