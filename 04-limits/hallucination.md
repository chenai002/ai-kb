# 10 · 为什么 AI 会一本正经地胡说

> 这是 AI 最让人抓狂的问题：它说错话时，比说对话时还自信。
> 这篇讲清楚幻觉怎么来的、怎么发现、怎么减少。

---

## 一、先看几个真实场景

**场景 1：编造引用**
> 你：「帮我找几篇关于 xxx 的论文」
> AI：「以下是三篇相关论文：[作者, 年份, 标题]…」
> 你一查：**这三篇都不存在。** 但格式、作者、年份看起来都特别真。

**场景 2：假装知道**
> 你：「我们公司的报销流程是什么？」
> AI：「一般企业报销流程为：提交申请 → 主管审批 → 财务审核 → 打款。」
> 它不知道你们公司，它说的是"一般情况"，但没告诉你这是猜的。

**场景 3：算错但很自信**
> 你：「38,472 × 9,731 等于多少？」
> AI：「等于 374,447,832。」
> （实际是 **374,447,032**，差了一位，但语气一样笃定。）
>
> 而你如果换个简单点的：「17 × 23」，它会直接算对。
> **问题不在于它"不会算"，而在于它不知道自己什么时候会算错。**

---

## 二、幻觉的四个根本原因

### 原因 1：它在"猜",不在"查"（最根本）

第 02 篇讲过：模型本质是在**预测下一个词**。

它的目标是"生成读起来合理的内容"，**不是"生成真实的内容"**。

```
训练数据里的模式：
  "论文引用通常格式为：[作者] ([年份]). [标题]. [期刊]."
  → 模型学会了「引用长这样」
  → 但不知道「这篇论文到底存不存在」
```

**这就是为什么它编的引用格式完美、内容全假。**

### 原因 2：没有"我不知道"的强激励

训练时，回答"不知道"通常得分不高（用户想要答案）。而"给个看起来合理的答案"更符合训练时的奖励。

所以模型**默认倾向给出答案**。

### 原因 3：知识截止 + 无实时信息

```
模型知道：训练截止日期前的事
模型不知道：之后的事、你的内部资料、实时数据
但它不会主动区分「我知道」和「我在猜」
```

### 原因 4：概率性生成

同一个问题问两次，可能一次对一次错。这不是"发挥失常"，是机制使然。

---

## 三、什么样的幻觉最危险

不是所有幻觉都一样危险。按危害排序：

| 类型 | 例子 | 危险度 |
| --- | --- | --- |
| **编造事实性数据** | 编造法条、论文、API 参数 | 🔴 极高 |
| **编造医疗/法律建议** | 说某个药可以治某病 | 🔴 极高 |
| **细节错误但整体合理** | 数字差一位、日期错一天 | 🟠 高（很难发现） |
| **过时的信息** | 说某个产品已停运（其实还在） | 🟠 高 |
| **风格化表达** | 说"我认为…"（它没有观点） | 🟢 低 |
| **小错误** | 把"的"写成"地" | 🟢 低 |

**最危险的是**：看起来合理、难以验证、但实际错误的内容。

## 四、怎么发现幻觉

### 4.1 三个信号

**信号 1：太具体了**

```
✅ 可疑：「据 2023 年 Q3 财报显示，该公司营收为 12.47 亿元」
✅ 正常：「一般来说，这类公司营收在十亿量级」
```

**越具体越要查**（除非它引用了你给它的资料）。

**信号 2：它没引用来源**

如果是基于资料回答，它应该能指出"来自哪一段"。
没有出处的具体数字，一律存疑。

**信号 3：符合你的"惊喜感"**

```
如果你读了觉得"哇，还能这样？"——大概率是编的。
```

### 4.2 验证方法

| 方法 | 适用 |
| --- | --- |
| 交叉验证（用另一个模型/搜索引擎查） | 通用 |
| 要求它给出处 | 便于检查 |
| 让它"复述"一遍再对比 | 找不一致 |
| 关键事实人工核对 | 唯一可靠 |

## 五、怎么减少幻觉（按有效性排序）

### ✅ 方法 1：给它资料（RAG）

```
请只根据下面的资料回答，资料里没有就说"资料未提及"。

<资料>
...</资料>
```

**有效性：★★★★★**
这是最有效的方法，因为它把"从记忆里猜"变成了"从资料里找"。

### ✅ 方法 2：要求引用出处

```
每个结论后面标注来自哪一段（用【1】【2】引用）。
```

**有效性：★★★★**
促使它基于资料，且便于你核查。

### ✅ 方法 3：明确允许"不知道"

```
如你不确定，请回答"我不确定"，不要编造。
```

**有效性：★★★**
降低概率，但不能消除。

### ✅ 方法 4：让它先思考再回答

```
请先列出你的推理步骤，再给出结论。
```

**有效性：★★★**
推理题、计算题效果明显。

### ✅ 方法 5：把精确计算交给工具

```
不要在脑子里算，请调用 calculator 工具。
```

**有效性：★★★★★**（对计算类问题）
这就是工具调用的价值（见第 08 篇）。

### ✅ 方法 6：降低 temperature

```
temperature: 0
```

**有效性：★★**
更稳定，但知识错误依然存在。

### ⚠️ 方法 7：多问几次取一致结果

```
同一个问题问 3 次，如果答案一致，可信度更高。
```

**有效性：★★★**（工程上叫 self-consistency）
但成本翻 3 倍。

### ❌ 错误的想法

| 想法 | 为什么不对 |
| --- | --- |
| "让它更严格地说'不知道'" | 它会过度拒绝，帮不上忙 |
| "换个更贵的模型就没幻觉了" | 减少但不会消除 |
| "微调能解决" | 不能，微调不会让它变诚实 |

## 六、不同场景的应对策略

| 场景 | 策略 |
| --- | --- |
| **闲聊、创意** | 幻觉无害，不用管 |
| **资料问答** | 必须 RAG + 强制引用 |
| **代码生成** | 必须跑测试；不要相信"这段代码能跑" |
| **数据分析** | 数字必须让它用工具算，不要让它"估" |
| **医疗/法律/金融** | 只做辅助，不直接给结论，必须人工复核 |
| **对外发布内容** | 所有事实性内容人工核对 |

---

## 七、一个重要的心态

> **把 AI 当成"很有信心但偶尔会记错的同事"，而不是"权威"。**

你会这样对待一个记性不太好的同事：
- 让他查清楚再说
- 关键数字自己核一遍
- 不确定的地方多问一句

对 AI 也该这样。

---

## 八、常见困惑

**Q：为什么幻觉时它一点犹豫都没有？**
因为它不是在"回忆"和"编造"之间切换，它只是在一个统一的过程中生成 token。它没有"元认知"来区分"我知道"和"我在猜"。

**Q：加了"不要编造"就没幻觉了吗？**
不会。它只是降低了倾向。要彻底避免，需要外部验证。

**Q：幻觉会随模型变强而消失吗？**
会减少，但不会消失。因为根本原因在于"生成"这个机制本身。

**Q：为什么它编的东西往往特别像真的？**
因为它学的正是"真实内容长什么样"。格式、术语、语气都是学来的。

**Q：有没有"幻觉检测"工具？**
有一些（用另一个模型判断、与检索结果比对），但都不可靠。**人工核对是唯一可靠的。**

---

## 九、用一句话解释给朋友听

> 「AI 不是在查资料，而是在'猜下一句最像真的话'。所以它编出来的内容格式完美、语气笃定，但全是假的。要减少它胡说，最有效的是把真实资料喂给它，并要求它只根据资料回答。」
